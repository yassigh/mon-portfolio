LoisirHub

Plateforme web et mobile permettant de découvrir, réserver et gérer des activités de loisirs avec plusieurs fonctionnalités intelligentes.

Voir sur GitHub

Objectif du projet

Développer une plateforme web et mobile dédiée aux activités de loisirs, permettant aux utilisateurs de découvrir, réserver et gérer leurs activités facilement.

Description

LoisirHub est un projet de fin d'étude (PFE) réalisé chez Hammamet Informatique Service. L'application propose une interface web et une application mobile connectées à une même base de données pour une expérience unifiée.

Technologies utilisées

Laravel React React Native MySQL PHP JavaScript

Logiciels & outils

VS Code Git GitHub MySQL Postman

Fonctionnalités

  • Inscription et connexion des utilisateurs
  • Découverte des activités de loisirs
  • Réservation d'activités en ligne
  • Gestion des réservations
  • Panneau d'administration
  • Application mobile (React Native)
  • Fonctionnalités intelligentes
  • Interface responsive

Stage PFE

  • Entreprise : Hammamet Informatique Service
  • Lieu : Nabeul, Tunisie
  • Durée : 5 mois
  • Période : Janvier — Mai 2025

Mon rôle

Développement backend avec Laravel, frontend avec React.js, application mobile avec React Native, et gestion de la base de données MySQL. Travail en équipe avec respect des délais du projet.
