5ademni.tn

Application web développée avec Symfony permettant de gérer des publications et d'intégrer plusieurs fonctionnalités modernes.

Voir sur GitHub Voir la Démo

Objectif du projet

Créer une plateforme web permettant aux utilisateurs de publier, consulter et gérer des publications de manière simple et efficace avec une interface moderne.

Description

5ademni.tn est une application web complète développée avec le framework Symfony. Elle permet la gestion des publications avec des fonctionnalités modernes comme l'authentification, le CRUD et des interfaces dynamiques.

Technologies utilisées

Symfony PHP MySQL JavaScript HTML CSS

Logiciels & outils

VS Code Symfony CLI Git GitHub phpMyAdmin

Fonctionnalités

  • Authentification des utilisateurs
  • Gestion des publications (CRUD)
  • Consultation des publications
  • Interface dynamique et responsive
  • Panneau d'administration
  • Gestion des données avec MySQL

Mon rôle

Développement full-stack de l'application avec Symfony, conception de la base de données, développement des interfaces utilisateur et intégration des fonctionnalités.
