E-commerce

Site de vente en ligne développé avec Symfony et MySQL dans le cadre d'un stage d'un mois chez Neapolis Arts à Nabeul en janvier 2024.

Voir sur GitHub Voir la Démo

Objectif du projet

Développer un site de vente en ligne permettant de présenter des produits et de faciliter leur gestion et leur commercialisation sur Internet.

Description

Application web e-commerce développée pendant un stage d'un mois chez Neapolis Arts à Nabeul. Le projet met en place une plateforme de vente en ligne avec une interface web responsive et une gestion des données via base de données.

Technologies utilisées

Symfony PHP MySQL HTML CSS JavaScript

Logiciels & outils

VS Code Symfony CLI MySQL Git GitHub Postman

Fonctionnalités

  • Présentation des produits
  • Gestion des produits (CRUD)
  • Gestion des catégories
  • Consultation des produits
  • Gestion des données avec MySQL
  • Interface web responsive
  • Fonctionnalités de vente en ligne

Stage

  • Entreprise : Neapolis Arts
  • Lieu : Nabeul, Tunisie
  • Durée : 1 mois
  • Période : Janvier 2024

Mon rôle

Participation à la conception et au développement du site e-commerce, notamment dans la partie développement web et gestion des données.
